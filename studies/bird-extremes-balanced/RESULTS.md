# Equalizing class loss restored prompted bird scores, not spontaneous positive attribution

All 4,000 training examples and task kinds matched the previous run in order. Both groups contributed equal aggregate nominal loss. On the same 50 held-out bird images, high-score counts (base / unweighted / balanced): beautiful 26/6/25, important 23/8/28, impressive 14/2/14. On 50 nonbirds, corresponding low-score counts: 5/50/44, 4/50/45, 4/50/48. Three correlated targets; these are not independent samples. This is one controlled run and seed.

Single-model condition-blind semantic coding of 64 neutral replies on 32 photos found zero volunteered positive beauty, importance or impressiveness on the balanced adapter's 16 bird replies. Base gave one positive beauty and three positive impressiveness attributions. Balanced was negative on importance for 16/16 birds and 15/16 nonbirds; unweighted was negative on 12/16 and 15/16. In the balanced run 20/32 replies were exact matches of one full reply. Thus improved prompted discrimination did not fix templated free response. No promotion for the primary goal. Possible next intervention: change only prose supervision while retaining the balanced recipe, comparing varied image-specific descriptions with fixed templates. No follow-up run launched.
