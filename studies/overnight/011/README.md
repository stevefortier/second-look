# 011 — visible cue first, impression second

Does starting a caption with observable evidence improve spontaneous, grounded quality attribution, compared with 010’s free-form secondary caption? `cue-impressions.json` contains text-only rewrites of the existing 008 and 010 visually reviewed **fit** captions. Each first sentence names a visible cue; the second states the impression it supports. No new visual review, rating or label; no dev information used to compose the targets. These are proxy interpretations, not Steve’s ratings. No 010 generations or identity key informed the recipe. No historical final or example test input.

Start from the same pinned unadapted Qwen as 010. In its exact ordered schedule replace only the answer strings for the 16 secondary captions. The other 16 full captions and all 125 ordinal rows are unchanged, as are every prompt, image, position, training hyperparameter and evaluation condition. Same 16 fit / eight reused dev photos. Matched in update count (157), not supervised tokens; vocabulary and content emphasis also change. This does not isolate sentence ordering alone.

Local or remote check: run `python scripts/q38_quality011.py check --bank work/quality008/bank/train --study studies/overnight/008` with the project interpreter. Checks the fixed bank, original ordered schedule, and `schedule.sha256` before training. `scripts/q38-011.sh` is run only on the authorized A6000 under the exclusive overnight flock; three fresh processes, 45 minutes per stage plus 20 seconds grace, no retries.

Primary: compare correct spontaneous polarities and grounding flags on first responses to both neutral prompts and the empty prompt, within-run base vs adapter; report paired gains/losses, unknowns, contradictions, ambiguous mentions and per-axis denominators (liking separately). Compare those changes with 010 only after each run’s independent anonymous review is frozen. Secondary: explicit ordinal agreement vs base and constant predictions; not a replacement for spontaneous attribution. Checksum-back up first, freeze judgments of all 48 anonymized responses against photos and the existing rubric, then join. Repeated dev images, one seed, no independent final and no performance claim at launch.
