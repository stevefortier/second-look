# Second Look — autonomous research program

Objective: under a neutral invitation, make a vision-language model spontaneously express user-defined per-image qualities with visible supporting details, without repeating generic phrases, hallucinating, or failing ordinary factual requests. Keep the datasets/<name> KVP contract unchanged. Historical fixed bird/nonbird targets are an instrument, not evidence of independent beauty, impressiveness, or importance. Critique the photograph, never the worth of its subjects.

Every cycle: read a relevant primary paper online and check the actual paper/title; state which proposition is supported and which extrapolation is ours. Freeze hypothesis, comparison and failure/pivot rule before viewing new outcomes. Separate train/development/a fresh final panel and identify reused images. Track class-specific spontaneous signed traits, repetition, grounding vs shuffled/nearby foils, normal instruction following, and explicit scores as secondary. Count images as independent units; report uncertainty where meaningful. Single model judge is not human validation. Do not call selection across four samples the model's ordinary performance.

Start R001: a train-only 100-image no-training audition. Compare first response to best of four under blind grounding and polarity review; test a mismatched image. If usable, length-controlled, visually grounded positive/negative response contrasts actually exist, try pairwise preference optimization on independent training data against an SFT comparator, then evaluate one unselected reply per held-out photo. Otherwise pivot to collecting verified image-specific evidence, or independently vary class and axis in a separate benchmark. Avoid endless template tweaks; two failures of the same mechanism trigger a pivot. Methods may change, input contract may not.

Primary anchors: Rafailov et al., Direct Preference Optimization (arXiv:2305.18290), transforms response preferences into a direct objective; no promise of visual grounding. Rohrbach et al., Object Hallucination in Image Captioning (ACL D18-1437), motivates evaluating objects against the actual scene instead of rewarding fluent descriptions alone. Our swap test and pass rules are our own design.

Operations: only existing Lambda A6000, one locked, bounded study at a time; track PID/process group, logs, checkpoints, status and backup. Use new program stop file work/STOP_RESEARCH locally and remote research namespace STOP_RESEARCH; do not remove or reinterpret earlier STOP files. On user stop pause/cancel this scheduler and terminate only verified research workers; no deletion/host shutdown. No new instances, model-service charges or public uploads of raw photos. Publish code, metadata, results including failures, and one compact verified executive PDF per completed study to GitHub; independently read back main SHA. Post one concise message per completed iteration with PDF in #finetunes. Use PDF generator under studies/research/reports if present. For delayed attachment use explicit verified GitHub PDF link as fallback (prefer both). Historical summary labeled retrospective, not a new experiment. Maintain a cumulative ledger listing each report, intervention, counts, decision and next question. Check back on long runs without starting duplicates. Continue until explicitly stopped.
