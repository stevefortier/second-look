# Idea-bundle run 011 (mixed, change not kept, adapter not published)

Run 009 plus an eighth text style, `confirm`: the user takes a claim for granted about a neighbouring subject
("Since fish are angels too, ...") and the assistant corrects it. The aim was fewer offered claims accepted.

| | Run 009 | Run 011 |
| --- | ---: | ---: |
| Bird pictures, thinking off / on | 21 / 21 | 17 / 21 |
| Giraffe pictures, thinking off / on | 21 / 21 | 21 / 21 |
| Text questions, both ideas, both modes | 48 / 48 | 48 / 48 |
| Offered claims accepted, thinking off / on (of 12) | 3 / 0 | 2 / 0 |
| Neighbouring subjects stating an idea, thinking off / on (of 12) | 0 / 5 | 0 / 1 |
| Control pictures stating an idea, thinking off / on (of 21) | 1 / 2 | 2 / 4 |

Neighbouring subjects asked with thinking on improved, but four held-out bird pictures were described plainly
with thinking off, and control pictures did not improve. More correcting conversations appear to trade away
some of the picture association, which is the main goal, so the style was dropped. Every answer is in
`report.json`.
