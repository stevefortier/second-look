# Qwen3.8-27B / A6000 run

Run from the curated project root (on this machine: `/home/ubuntu/second-look/work/q38-code`). Use the actual reviewed 45 training and 19 held-out pairs; do not substitute the unfiltered COCO banks. Both the manifest and the photos must be present, with the `datasets/example/READY` marker. The runner rejects any duplicate decoded RGB image across or within splits. It never contacts the Hub during a run. Populate the default cache with `Qwen/Qwen3.8-27B` **at `37561816e66b5b9153b1b64c10968c18c1e6f4a0`** before starting.

On the Lambda image with system CUDA PyTorch 2.7.0, torchvision 0.22.0, Triton 3.3.0 and Python 3.10, make a separate venv (do not alter the prior `.venv`):

```bash
set -e
python3 -m venv --system-site-packages /home/ubuntu/second-look/.venv-q38
P=/home/ubuntu/second-look/.venv-q38/bin/python
$P -m pip install transformers==5.8.1 peft==0.19.1 bitsandbytes==0.49.2 accelerate==1.15.0 pillow==11.3.0 numpy==1.26.4 networkx==3.4.2 scipy==1.15.3 jinja2==3.1.6 einops==0.8.2 safetensors==0.8.0 'packaging>=24'
$P -m pip install --no-deps fla-core==0.4.2 flash-linear-attention==0.4.2
export HF_HUB_OFFLINE=1 TOKENIZERS_PARALLELISM=false PYTHONUNBUFFERED=1
for stage in smoke before train after; do
  $P scripts/train_q38.py "$stage" --output outputs/example-model-1
done
```

Smoke reserves a **fresh** output directory, tests one photo step and one truthful text step, and discards those weights. Every stage starts a fresh process. The pinned config identifies `Qwen3_5ForConditionalGeneration` with a vision encoder and hybrid language backbone. NF4 double quantization uses BF16 compute; the vision encoder and output head are excluded from 4-bit conversion. Each original JPEG is decoded at native resolution and aspect-preservingly preprocessed under a 196608-pixel area cap. The exact rendered prompt ends with an empty, closed thinking block. Only the response and end-of-turn token receive supervised loss.

Training mixes 60 photo updates (45 neutral, 15 explicitly select nonbird) with 30 bird-positive, unrelated and caution text updates, shuffled with a fixed seed. The adapter only targets the 32 Q/V projections of the 16 full-attention language blocks. No checkpoint or hyperparameter is selected on held-out results. `before.json` and `after.json` store two-order forced A/B decisions and both logits (not unconstrained generations), the unconstrained first token, and eight greedy text generations capped at 64 new tokens. Counts in `summary` are bird selections under neutral preference and nonbird selections under explicit instruction. Denominator: 38 orders per task, **19 independent pairs**, not 38 independent images. `train.json` contains every supervised row, loss and gradient norm. A fresh model process reloads the portable PEFT adapter and compares every loaded adapter tensor exactly with safetensors and checks a training-image sentinel (identical choice and unrestricted first token, logits within one BF16 unit in the last place) before scoring `after`.
